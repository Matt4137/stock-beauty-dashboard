Stock & Beauty Dashboard
![Dashboard de StockVision](stck%b.png)

Dashboard interactivo desarrollado con Python y Streamlit para analizar productos, precios, marcas y niveles de inventario.

<h2>Funcionalidades</h2><ul><li>Indicadores generales de productos e inventario.</li><li>Filtrar por categoría, marca y rango de precio.</li><li>Gráficos interactivos.</li><li>Búsqueda de productos.</li><li>Identificar productos con stock crítico.</li><li>Descarga de datos en formato CSV.</li></ul>

<h2>Tecnologías utilizadas</h2><ul><li>Python</li><li>Streamlit</li><li>Pandas</li><li>Plotly</li></ul>


Ejecución local

Descargar el repositorio.

Ejecutar la aplicación:

Haz doble clic en el archivo `EJECUTAR.bat`.

Este archivo instalará las dependencias necesarias e iniciará automáticamente la aplicación en el navegador.

En el navegador se abrira:
http://localhost:8501
